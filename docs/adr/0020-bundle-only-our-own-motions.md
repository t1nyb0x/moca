# ADR-0020: 同梱する動きは自分たちで作ったものに限る

- 状態: 採択
- 日付: 2026-09-05
- 関連: 要件 F-15、[ADR-0019](0019-gestures-from-user-vrma.md)、[ADR-0017](0017-vrm-pmx-only.md)

## 文脈

0.8 で身振りの足回りを入れた。VRMA を割り当てれば返答のタグで動く（ADR-0019）。
ただし **動きそのものは一つも持っていない。** 利用者が VRMA を用意して初めて
何かが起きる。

これは「入れたのに誰も使えない機能」になりやすい。VRMA を手元に持っている人は
少なく、作るには Blender などの道具と手付けの手間が要る。試す前に諦められると、
動くかどうかの判断すらしてもらえない。

ADR-0019 は同梱の道を閉じてはおらず、「同梱物を増やす判断は別途行う」として
いた。その判断をここで行う。

## 決定

**自分たちで作った動きは同梱する。第三者が作った動きは同梱しない。**

基準は品質でも大きさでもなく **出所** に置く。

### なぜ出所を基準にするか

配布物に他人のファイルを混ぜると、**再配布の可否・改変の可否・表示義務が
ファイルごとに違う** ものを抱え込むことになる。moca はインストーラを配る。
条件は取り込んだ時点で確かめれば済むものではなく、配り続けるあいだ確かめ
続けねばならない。数が増えれば必ず取りこぼす。

自分たちで作ったものなら、その負担がまるごと無い。加えて、

- **直せる。** 立ち姿を変えたら動きも合わせて直す、という追随ができる
- **品質の責任を持てる。** 良し悪しを判断できないファイル（ADR-0019）と違い、
  自分で作ったものは目で見て直せる
- **説明できる。** どういう狙いでその角度なのかを文書に残せる

「良い動きを見つけたので同梱する」は採らない。良し悪しの判断は、それを配って
よいかどうかとは無関係だからである。

### 作り方は問わない。出所だけを問う

自分たちで作ったものであれば、数値で組み立てても、撮影して整えても構わない。
実際、最初は角度と時刻で組み立てたが、**実写の身振りを見比べるうちに、撮影した
ものを切り出すほうが早く良いところへ着く**と分かった。人の動きの「間」は、
数値を睨んで当てるより、撮って削るほうが速い。

いずれにせよ**版管理へ入れるのは生成物と作り方の両方**とする。利用者にも
ビルドする人にも、生成環境を求めないためである。撮影ものについては、元の撮影・
切り出しの範囲・掛けた処理を `src-tauri/resources/gestures/README.md` に残す。

### 数値で組み立てる場合

`scripts/vrma/` に glTF を組み立てる部品を置いてある。**作り方を版管理へ
入れる。**

- 直して走らせ直せば作り直せる。繰り返し詰められる
- 差分が読める。「肘を 5 度下げた」が履歴に残る
- **符号の取り違えを機械で捕まえられる。** 正規化された骨は軸がモデルの軸と
  揃っているので、前進運動学で手の位置を計算できる。「手が肘より上にあるか」
  「肘が体から離れていないか」を試験で確かめる。実機で動かすまで気づけない
  類の誤りだったので、ここは機械に見させる

生成物（`.vrma`）も版管理へ入れる。**利用者にもビルドする人にも生成環境を
求めないため** である。ビルドの手順は 0.8 までと変わらない。

### 既定では割り当てない

同梱していても、キャラクターへ自動では割り当てない。ADR-0019 の
「割り当てが無ければプロンプトは 0.7 と一字も変わらない」を保つ。設定画面の
「同梱の身振りを追加」で、利用者が明示的に足す。

黙って足すと、システムプロンプトに知らないタグ名が載り、返答に `[wave]` が
出るようになる。**利用者が何も選んでいないのに振る舞いが変わる** のは、
0.8 で避けたはずのものである。

## 帰結

- `src-tauri/resources/gestures/*.vrma` を配布物へ含める。インストール先の
  `resources` から `motion_bundled` が並べ、設定画面が一押しで足す
- 同梱物が欠けていても機能は動く。`motion_bundled` は空で返し、画面が
  「見つかりませんでした」と出す
- 撮影したものを整えるのは `node scripts/vrma-edit.mjs`。手で `.vrma` を
  編集しない。掛けたコマンドは `resources/gestures/README.md` に残す
- 同梱の動きも VRM のみが対象。PMX には当たらない（ADR-0019 と同じ）
- 利用者が用意した VRMA の扱いは何も変わらない。同梱物は上乗せであって、
  置き換えではない
