# 同梱の身振り

**ここに置くのは自分たちで作った動きだけ**（[ADR-0020](../../../docs/adr/0020-bundle-only-our-own-motions.md)）。
拾ってきた VRMA は、出来がよくても置かない。再配布の条件をファイルごとに
抱え込まないためである。

## wave.vrma — 手を振る

自分たちで撮影したモーションから切り出した。撮影は XR-Animator。

そのままでは使えないので、`scripts/vrma-edit.mjs` で次のように整えてある。

```
node scripts/vrma-edit.mjs <撮影したもの>.vrma src-tauri/resources/gestures/wave.vrma \
  --from 4.35 --to 9.32 --bones right-arm --smooth 3 --max-speed 350 --name wave
```

- **4.35〜9.32 秒を切り出した。** 12 秒の撮影のうち、腕を上げてから下ろすまで
- **右腕と右手だけを残した**（18 本）。頭・胴・脚・左腕・腰の移動は落とす。
  **触っていない骨は moca の手続きの動きが動かし続ける**ので、振っているあいだも
  立ち姿・体重移動・呼吸が生きる。全身を残すと、撮影で解けていない側の腕まで
  載って人形のように見える
- **均しと速さの頭打ちを掛けた。** 撮影は推定を見失うと 1 コマで数十度跳ぶ。
  指で 1420 度/秒、前腕で 1281 度/秒の跳ねがあった

両端の姿勢には手を入れていない。**立ち姿への着地は moca 側が行う**
（`src/domain/motion/retarget.ts`、要件 F-15-3）。ここで決め打ちすると、腕が
その角度まで持ち上がって跳ねる。
